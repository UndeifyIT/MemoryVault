# NOW

NOW is a social map of places, starting in Lagos: users post about places they've been, follow each other and see where people actually go (decision 0006). Repo: https://github.com/UndeifyIT/Now (default branch `main`, private). Building the private beta (milestone M0): app skeleton, data layer and first database tables are in the repo. Undeify's first priority since 2026-10-14.
